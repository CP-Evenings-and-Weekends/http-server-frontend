# Frontend for HTTP Server

In the last class, you had to modify an [http server](https://github.com/CP-Evenings-and-Weekends/http-server).

Today, you'll build on that and end up writing a frontend for it.

### Step 1
Copy over your server code from the http server.  Create a third endpoint and return something interesting in the form of JSON

### Step 2
Create an HTML/CSS/JS frontend that uses the endpoint you just created.  You'll likely get a [CORS error](https://www.bannerbear.com/blog/what-is-a-cors-error-and-how-to-fix-it-3-ways/#:~:text=To%20get%20rid%20of%20a,Methods%20headers%20to%20the%20responses.) (Do not install any browser extensions to fix this--remember that you have full control over the headers that your server sends).

### Step 3
Include a 3rd-party API.
